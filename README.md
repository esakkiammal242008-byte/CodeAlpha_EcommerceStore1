# CodeAlpha E-Commerce Store

A responsive E-Commerce Store developed using HTML, CSS, and JavaScript.

## Features

- Product Listing
- Product Search
- Product Categories
- Product Ratings
- Product Discounts
- Add to Cart
- Remove from Cart
- Shopping Cart Total Calculation
- Checkout System
- Order Placement
- Responsive Design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
